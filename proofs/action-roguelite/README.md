# Proof Action Roguelite

Primary defining proof consumer for capability program Phase 13 (Run Lifecycle & Roguelite Meta-Progression).

Demonstrates:
- Top-down dungeon room generation via `sw2d.generation`.
- Active run lifecycle and permadeath loop via `sw2d.runs`.
- Persistent meta-progression via `sw2d.progression`.
- Item inventory via `sw2d.items`.
- Combat health and damage via `sw2d.combat`.
