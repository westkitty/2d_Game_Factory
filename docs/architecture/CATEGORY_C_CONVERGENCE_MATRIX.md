## How to read the tables

- **Category-C waves**: `W<n>` per `CATEGORY_C_CAPABILITY_PROGRAM_STATE.md` (derived from the
  packs a preset requires and the generator stamp its id selects in
  `packages/cli/src/generator/packConfig.ts`); `first-ten` = capability program ADR-0018..0027;
  `CONV` = changed by this convergence program.
- **maturity before → after**: catalog field in `packages/presets/src/catalog/*.ts`, pinned by
  `packages/presets/test/honesty.test.ts` and derived mechanically from `proofs/` by
  `proofEvidence.test.ts`.
- **proof game**: `frozen (pre-program)` = the 23 proofs committed before this program, not
  regenerated; `committed this program` = the unmodified canonical factory output
  (`npm run sw2d -- new proof-<id> --preset <id>`, moved to `proofs/<id>/`) plus a frozen
  `PROOF_CONTRACT.md` and a spec in `packages/qa/proof-specs/`.
- **minimum genre-defining journey**: the `## Defining journey` of each `PROOF_CONTRACT.md`,
  verbatim — it is what `npm run qa:proof` drives in a real browser, not a checklist.
- **classification** of the first known limitation: A still true · B closed by an existing
  reusable capability · C closed by Category-C work · D legitimately game-specific · E stale.
  Every string was re-read against the generated game this program played; the Category-C waves
  had already rewritten each one to the "X is reusable (pack); Y is not" form, so every entry is
  **A**. One was sharpened for honesty (`auto-battler`: the lineup pick is presentation).
  `traditional-platformer` states no limitation and, after this program, needs none for its
  generated loop (see "Integration debt repaired").
