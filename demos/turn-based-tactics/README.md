# Turn Based Tactics

Generated by `npm run sw2d -- new turn-based-tactics --preset turn-based-tactics` from the `turn-based-tactics` preset
(family: strategy-defense). This is a **recipe**, not a finished game - see "Known preset
limitations" below for what is deliberately not implemented yet.

## How to run

```bash
npm --workspace turn-based-tactics run dev
```

## How to validate

```bash
npm run sw2d -- validate turn-based-tactics
```

Runs manifest/content schema validation, TypeScript, this game's tests, a production build,
and (when a real browser is available) a focused smoke journey.

## How to build

```bash
npm run sw2d -- build turn-based-tactics
```

Produces `games/turn-based-tactics/dist/` - a self-contained static build with no required external
network request.

## How to pack

```bash
npm run sw2d -- pack turn-based-tactics
```

Produces `games/turn-based-tactics/pack/` - the same build, with source/tests/node_modules excluded,
ready to serve from any static file host.

## Where normal game content lives

```text
NORMAL GAME WORK              FACTORY/RUNTIME WORK (do not edit from here)
content/**                    packages/contracts/**
public/**                     packages/runtime/**
themes/**                     shared system packs (packages/packs/**)
src/game-specific/**          shared controllers (packages/runtime/src/controllers/**)
```

Edit `content/game.json` (manifest, packs, bindings/accessibility defaults),
`content/tuning.json` (tuning values), `content/themes/**` (presentation), and
`src/game-specific/**` (this game's own mechanics) freely. This game consumes the
factory's reusable packages as local workspace dependencies; it never copies their source.

## Composition

- Controller family/families: grid, ui-simulation
- Required packs (enabled by default): sw2d.strategy, sw2d.combat
- Optional packs (available, not enabled by default - add to content/game.json's systemPacks to use): sw2d.ai, sw2d.world, sw2d.world-entities
- Content roles this preset expects: tuning, levels

## Known preset limitations

- Grid/strategy foundations exist, but movement range, attack range, pathfinding, and turn-action resolution are not reusable systems yet.

## How to add a level

```bash
npm run sw2d -- add-level turn-based-tactics <level-id>
```

Writes `content/levels/<level-id>.json` - a valid Tiled JSON export using the Phase 6
object-class subset (PlayerSpawn, Checkpoint, Collectible, Hazard, Exit, Solid). Reference it
as a content document named `levels/<level-id>`.

## How to add a theme

```bash
npm run sw2d -- add-theme turn-based-tactics <theme-id>
```

Writes `content/themes/<theme-id>/theme.json` - a valid local ThemeManifest. Swapping
which theme `src/content.ts` loads changes presentation only; it never changes gameplay
data.
